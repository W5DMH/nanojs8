NanoJS8

A pocket JS8 amateur-radio transceiver for the LilyGO T-Deck Plus.

Install firmware

Your browser doesn't support Web Serial. Use Chrome or Edge on a desktop OS (Windows, macOS, Linux, or ChromeOS). Web Serial isn't available in this context. Make sure the page is loaded over HTTPS and try again.

Chrome or Edge required · Desktop only · ~30 seconds

Before you start

  • Connect your T-Deck Plus to your computer with a USB-C data cable
  • Power the T-Deck Plus on (slide switch on the side)
  • Make sure no other app (e.g. Arduino IDE serial monitor) has the COM port open

What the installer does

  1. Browser prompts you to select the T-Deck Plus's serial port
  2. Flashes the bootloader, app, and JSC dictionary (~4 MB)
  3. Device reboots into NanoJS8 — the home screen will appear on the T-Deck display

Existing data on the device's NVS (saved settings, INBOX) is preserved by default. Tick "Erase device" in the installer if you want a fresh start.

First-boot setup

  1. From HOME press Tab until you reach SETUP
  2. Enter your callsign and Maidenhead grid (e.g. EN83)
  3. Pick your radio profile (default digirig-rts-only works with most radios that accept RTS PTT)
  4. Tune your radio to 7.078 MHz USB (the standard JS8 calling frequency on 40 m)
  5. Connect the audio adapter (e.g. DigiRig) via USB-C Y-cable

UTC time will be acquired automatically from the on-board GPS within a few minutes of getting outdoor visibility to the sky. You can also enter UTC manually on SETUP row 6 if you're indoors.

Hardware you'll need

Device
LilyGO T-Deck Plus (16 MB flash + 8 MB PSRAM, has GPS)
Radio interface
DigiRig (or similar USB sound + RTS-PTT adapter)
Cabling
USB-C Y-cable so the T-Deck and DigiRig can both be powered
Radio
Any HF SSB transceiver with a PTT line — verified on Xiegu G90

Status & limitations

This is a pre-alpha test build. It has been on-air verified for bidirectional MSG/ACK between W5DMH and KD8PGB on 40 m JS8 Normal mode. Expect rough edges, occasional UI glitches, and reduced sensitivity vs. desktop JS8Call. It is your responsibility to ensure you are operating within your licence privileges.
  • JS8 Normal mode only (Slow / Fast / Turbo not yet supported)
  • Tested against stock JS8Call as a reference station
  • Group @GHOSTNET is the test net frequented by initial testers
  • Report issues at github.com/W5DMH/nanojs8/issues

Alternatives to one-click flashing

If your browser doesn't support Web Serial, or you'd rather flash by hand:

  1. Download nanojs8-merged.bin from the latest GitHub Release
  2. Install esptool (pip install esptool)
  3. Run:
    esptool.py --chip esp32s3 --port COM<n> write_flash 0x0 nanojs8-merged.bin
